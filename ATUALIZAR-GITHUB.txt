OXPROMPTER V1.1.1 — GITHUB PAGES

1. Exporte os roteiros antes de atualizar.
2. Extraia este ZIP.
3. Envie index.html, manifest.json, sw.js, .nojekyll e as pastas js, css, icons e vendor para a pasta que o GitHub Pages publica (raiz ou docs, conforme sua configuração). Substitua os arquivos anteriores.
4. O index.html deve ficar diretamente nessa pasta; não crie uma pasta extra ao redor destes arquivos.
5. Confirme o commit e aguarde o GitHub Pages concluir a publicação.
6. Feche as abas/PWA antigas e reabra o endereço HTTPS. Confira V1.1.1 na abertura.

Não limpe os dados do navegador. Este pacote não contém senhas, roteiros ou gravações pessoais. Teste primeiro em 720p/30 fps, segurando o aparelho na orientação escolhida.
