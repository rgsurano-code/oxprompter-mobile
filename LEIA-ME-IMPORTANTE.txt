2. Extraia este ZIP.

4. Preserve uma branch/cópia anterior antes de atualizar.
5. Publique pelo GitHub Pages como já faz e abra o mesmo endereço HTTPS.
6. Feche abas/PWA antigas antes de reabrir para atualizar o cache. Não limpe dados do site sem backup.
